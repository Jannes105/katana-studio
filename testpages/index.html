Katana Studio – test pages

Feasibility tests for an Android editor for the Katana 100 Gen 3. Connect the amp to the phone with a USB cable first.

USB test Dump the USB descriptors, claim the MIDI interface, send an identity request, read the patch, measure timing and try three rehearsal controls. Runs over WebUSB in Chrome and over the native plugin inside the test APK. Capture Record what the amp sends, to answer open protocol questions.
